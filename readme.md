# Shoplifting Detection System

This is a shoplifting detection system built using Python and various libraries. The system uses a webcam or a video file as input and applies object detection to identify suspicious activities.

## Instructions

1. Create a virtual environment: `python -m venv venv`
2. Activate the virtual environment: `\venv\Scripts\Activate.ps1`
3. Upgrade pip: `python -m pip install --upgrade pip`
4. Install the required libraries: `pip install -r requirements.txt`
5. Run the main script: `python main.py`

The system will start a web server and you can access the shoplifting detection system through a web browser.
