
# Suspicious Activity Detection System

This project detects suspicious activity in shoplifting scenarios using YOLOv8 and an XGBoost model. The system processes video streams, identifies suspicious behavior, and saves annotated images to the `outputs` directory.

## Features
- Real-time video stream processing.
- Detection of suspicious activity with alerts.
- Saves suspicious frames with annotations.
- Responsive UI using Tailwind CSS.

## Installation

### Prerequisites
- Python 3.8+
- `pip` installed

### Steps
1. Clone the repository:
   open PowerShell
   ```bash
   cd SHOPLIFTING
   ```
2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   # For Windows PowerShell
   .\venv\Scripts\Activate.ps1
   ```
3. Upgrade pip and install dependencies:
   ```bash
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. Run the application:
   ```bash
   python main.py
   ```

## Usage
1. Access the application in your web browser at `http://127.0.0.1:5000`.
2. Upload a video for processing.
3. View real-time detection with annotated frames.
4. Suspicious frames will be saved in the `outputs` directory.
5. After processing, a message will confirm the saved frames.
